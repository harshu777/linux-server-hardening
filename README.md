# Linux Server Hardening

## Overview
This repository contains baseline Linux server hardening practices implemented across production and staging environments.

## Scope
- SSH hardening
- Firewall baseline configuration
- Fail2Ban intrusion prevention
- System & kernel hardening
- Audit logging
- User & permission management

## Environments
- Ubuntu 20.04 / 22.04 / 24.04
- Debian-based systems
- Cloud & bare-metal servers

## Repository Contents
- `scripts/` – Generic hardening scripts
- `templates/` – Configuration templates
- `checklist/` – Operational hardening checklist

## Security Disclaimer
All content is generalized and sanitized. Review and test before applying in production.
